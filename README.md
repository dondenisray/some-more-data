Mini Project – Contact Center & MICE
🔎 Overview

Mini Business Intelligence project simulating operational reporting for:

📞 Contact Center performance

🏨 MICE (Group Sales) revenue

Built using SQL Server, Python (pandas) and Power BI.

🛠 Stack

SQL Server

Python (pandas) – data validation

Power BI – KPI dashboard & DAX

📈 KPIs
Contact Center

Total Calls

Handled Rate

Average Wait Time

Monthly trend

MICE Sales

Total Revenue

Total Bookings

Avg Revenue per Booking

🧠 Key Concepts

Aggregations (SUM, COUNT, AVG)

Safe ratios using DIVIDE()

Data quality checks (nulls, duplicates, negatives)

Conditional formatting in DAX

Executive-style dashboard layout

🎯 Purpose

Demonstrates operational BI thinking:

KPI logic

Data validation mindset

Structured reporting

Business-focused analysis
